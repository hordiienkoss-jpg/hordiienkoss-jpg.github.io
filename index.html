перевірка

Не вірте жодному слову вище.

Ця сторінка вміє перевірити сама себе. Натисніть, і вона порахує власну вагу і власний час завантаження прямо зараз, на вашому пристрої і вашому зв'язку. Числа справжні, беруться з браузера.

···вага сторінки без відео
···час до першого показу
···запитів до сервера

Заміряно щойно, у вашому браузері. Оновіть сторінку і перевірте ще раз. Відео вгорі важить 7.2 МБ і вантажиться окремо, вже після того, як сторінка готова до читання. На телефони воно не вантажиться взагалі.

код

Код, який зможе підхопити хтось інший.

Найбільший ризик при замовленні сайту це не ціна. Це залишитись прив'язаним до однієї людини, бо ніхто інший не розбереться в тому, що вона написала.

Мої сайти це один файл index.html і тека assets. Без збірки, без фреймворків, без залежностей, які застаріють через рік. Відкривається будь-яким редактором. Продовжується будь-ким.

Праворуч справжній шматок з робочого файла. Цю сторінку теж можна відкрити через «переглянути код сторінки».

nytka / assets / app.js

function requestSeek(t) {
  if (!video.duration) return;
  t = Math.round(t / FRAME) * FRAME;
  if (Math.abs(t - lastSeekAt) < FRAME * 0.5) return;
  lastSeekAt = t;
  if (seekBusy) { pendingTime = t; return; }
  seekBusy = true;
  video.currentTime = t;
}

video.addEventListener('seeked', function () {
  seekBusy = false;
  if (pendingTime !== null) {
    var t = pendingTime;
    pendingTime = null;
    requestSeek(t);
  }
});

Перемотка відео вирівняна по сітці кадрів і не накладається сама на себе. Саме через це прокрут не смикається.

Перелік того, що входить, ви отримуєте до початку роботи. Якщо посеред роботи ви захочете щось понад цей перелік, я спершу назву ціну і дочекаюсь вашої відповіді.
